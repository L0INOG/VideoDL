## 🤖 一 · 如果你是 AI

### 项目说明

这是一个 **Android 视频下载器**：用户从抖音 / B站 / 快手 / 小红书复制分享链接（或系统"分享到"本 App），App **在本地**完成解析，拿到无水印直链后把视频或图集下载到公共下载目录，全程不经过任何第三方解析服务器。

---

## 🙋 二 · 如果你是人类

### 这是个啥？

安卓手机上的**视频保存小工具**

**没有广告、没有解析次数限制、完全免费**

### 它能干什么

- **抖音**：视频和图片；
- **B站**：视频；
- **快手**：视频；
- **小红书**：视频和图片；

### 怎么安装

把 `dist/VideoDL-1.0.apk` 传到手机上安装

### 怎么用

在抖音/B站/快手/小红书里点「分享」→「复制链接」
